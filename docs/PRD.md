# PRD — 小红书行业账号 ID 采集工具

## 基本信息

- **项目名称**: 小红书行业账号 ID 采集工具
- **版本**: v1.0
- **编写人**: PM
- **编写日期**: 2026-05-28
- **状态**: 草稿

## 1. 背景与目标

### 1.1 背景

在进行行业竞品分析、KOL 筛选、内容监控等工作中，需要获取特定行业下**尽可能全量**的小红书账号信息。手动逐个搜索效率极低，且单关键词搜索只能覆盖行业的极小部分账号。

### 1.2 目标

开发一款可复用的工具，通过**多策略交叉搜索 + 链式扩展**的方式，逼近行业的全量账号覆盖。支持：
- 多关键词穷举搜索
- 已知账号的社交链路挖掘（关注/粉丝/笔记标签等）
- 话题/标签页遍历
- 自动提取每个账号的唯一标识（hash ID）
- 输出结构化的 Markdown 报告
- 将工具封装为可复用的技能（Skill），支持一键运行

## 2. 用户故事

| 角色 | 故事 |

## 3. 功能需求

### 3.1 全量采集策略

为逼近行业全量账号覆盖，采用**多策略交叉搜索 + 链式扩展**方案。

#### 3.1.1 关键词穷举搜索（广度覆盖）
- 输入一批行业种子关键词，自动扩展为同义词/长尾词/细分词列表
- 每个关键词分别搜索用户类型结果
- 自动去重合并
- 示例输入：
  ```json
  {
    "industry": "美容护肤",
    "keywords": ["美容护肤", "护肤技巧", "好物推荐", "成分党", "敏感肌护理"],
    "expand_synonyms": true
  }
  ```

#### 3.1.2 社交链路挖掘（深度扩展）
- **关注链**：遍历已知账号的关注列表，发现同行业账号
- **粉丝链**：遍历已知账号的粉丝列表（头部粉丝），筛选同行业账号
- **笔记标签链**：提取已知账号热门笔记的标签/话题，搜索标签下的账号
- **互动链**：分析热门笔记的评论/点赞用户，筛选行业活跃账号

#### 3.1.3 话题/标签页遍历
- 识别行业相关的热门话题（hashtag）
- 遍历话题页下的内容发布者
- 从话题关联话题继续扩展

#### 3.1.4 持续迭代机制
- 不设账号数量上限，持续挖掘直到探索路径全部走完
- 链路扩展采用 BFS（广度优先）策略，逐层展开
- 每轮输出增量统计，展示采集进度
- 输出最终统计：关键词覆盖数、链路扩展数、去重总数、采集轮数

### 3.2 双模式搜索

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **浏览器模式** | 通过浏览器自动化（Playwright）打开小红书搜索页，解析搜索结果 | 需要图形化交互、处理反爬时 |
| **API 模式** | 通过小红书公开 API / 搜索接口获取数据 | 快速批量采集、无需渲染时 |

**策略**：
- 默认优先尝试 API 模式（速度快）
- API 被限流或失败时自动降级为浏览器模式
- 可在配置中手动指定使用哪种模式

### 3.3 账号信息提取

对每个搜索结果中的账号，提取以下信息：

| 字段 | 说明 | 来源 |
|------|------|------|
| 昵称 | 账号显示名称 | 搜索结果页 |
| hash ID | URL 中的唯一标识串（如 `5ec4a3c1000000000100xxxx`）| 账号主页 URL 解析 |
| 简介 | 账号简介/签名 | 搜索结果或主页 |
| 粉丝数 | 粉丝数量级 | 搜索结果或主页 |
| 笔记数 | 发布笔记数量 | 搜索结果或主页 |
| 主页链接 | `https://www.xiaohongshu.com/user/profile/{hash_id}` | 拼接生成 |

### 3.4 输出格式

**Markdown 表格**（初级版本）：
```markdown
# 小红书行业账号ID - 美容护肤

搜索关键词: 美容护肤, 护肤技巧, 好物推荐, 成分党, 敏感肌护理
采集时间: 2026-05-28 14:00

| 序号 | 昵称 | hash ID | 简介 | 粉丝数 | 笔记数 | 主页链接 |
|------|------|---------|------|--------|--------|---------|
| 1 | 某某护肤 | 5ec4a3c1000000000100xxxx | 专注敏感肌... | 12.3w | 456 | [链接](...) |
```

**输出文件**：`小红书行业id.md`（文件名可配置）

## 4. 非功能需求

### 4.1 可靠性
- 单关键词搜索失败不影响其他关键词
- 自动重试机制（最多 3 次）
- 搜索频率控制，避免触发风控

### 4.2 可复用性
- 封装为 Skill（技能），放在 `skills/` 目录下
- 支持配置参数：搜索模式、关键词列表、输出路径
- 脚本独立可运行

### 4.3 可观测性
- 执行过程输出日志（搜索进度、成功/失败数）
- 最终输出统计摘要

## 5. 边界与约束

| 约束项 | 说明 |
|--------|------|
| 数据源 | 仅限小红书公开可访问的内容（搜索页、公开主页、公开话题页） |
| 账号范围 | **目标为逼近全量**，但受限于小红书平台搜索算法和数据开放程度，理论上无法达到 100% 全量。通过多策略交叉可达到高覆盖率 |
| 频率限制 | 严格遵守小红书平台的访问频率限制，设置合理的请求间隔和随机延迟 |
| 合法合规 | 仅用于行业分析，不涉及爬取用户隐私数据、不登录他人账号、不暴力破解 |
| 社交链路限制 | 关注/粉丝列表仅能获取公开可见的部分，部分账号可能设置隐私限制 |
| 输出格式 | v1.0 仅支持 Markdown，v2.0 升级 HTML |

## 6. 验收标准

- [ ] 输入行业关键词后，多策略搜索持续执行，输出 `小红书行业id.md`
- [ ] 表格中包含所有已采集的账号信息（昵称、hash ID、简介、粉丝数、笔记数、链接）
- [ ] 关键词穷举搜索正常执行并去重
- [ ] 社交链路挖掘（关注链/粉丝链/标签链）至少实现一种并正常运行
- [ ] 双模式（浏览器/API）均可正常工作，API 失败自动切换浏览器
- [ ] 输出采集统计摘要（关键词覆盖数、链路扩展数、去重总数、采集轮数）
- [ ] 单个关键词/链路失败不影响整体流程
- [ ] 已封装为 Skill，可通过 `python3 skills/xiaohongshu_id_collector/main.py` 一键运行
- [ ] 输出文件路径符合预期
