# 小红书行业账号ID采集工具 — 技术方案 Plan

> 任务ID：TASK-002 | 状态：进行中 | 版本：v1.0

---

## 一、需求概述

采集小红书特定行业的账号ID及账号链接，支持按关键词搜索或客户指定行业。

### 输出数据
- **小红书账号ID**（即用户主页标识）
- **账号链接**（可访问的用户主页URL）

### 采集方式
- 按关键词搜索用户
- 按行业/品类种子账号扩展
- 支持全量采集

### 部署方式
三种模式都支持：脚本工具、本地服务、Web端

---

## 二、技术选型

### 2.1 数据采集方案对比

| 方案 | 优点 | 缺点 | 推荐度 |
|------|------|------|:------:|
| **爬虫采集**（Playwright自动化） | 数据精准、可控性强 | 需要维护反爬策略 | ⭐⭐⭐⭐⭐ |
| 第三方API（如新红、千瓜等） | 开发成本低 | 收费、覆盖率受限 | ⭐⭐⭐ |
| 小红书官方API | 合规 | 权限门槛高、限制多 | ⭐⭐ |

**推荐方案：Playwright + 反爬策略**

### 2.2 技术栈

| 技术 | 用途 |
|------|------|
| **Python 3.10+** | 主开发语言 |
| **Playwright** | 浏览器自动化、页面数据采集 |
| **FastAPI** | 本地/云端服务接口 |
| **Streamlit** | Web管理界面 |
| **SQLite / JSON** | 本地数据存储 |
| **Docker** | 容器化部署 |

### 2.3 核心对抗策略
- 账号池 + 随机切换
- 请求间隔随机化（模拟人类行为）
- Cookie/Session 管理
- IP代理轮换（可选）
- User-Agent 随机化

## 四、功能模块设计

### 模块1：关键词管理
- 支持批量导入关键词
- 支持按行业分组
- 关键词去重、优先级排序

### 模块2：搜索采集
- 按关键词搜索用户列表
- 递归采集搜索结果（翻页）
- 提取字段：用户ID、昵称、主页链接

### 模块3：详情补全（可选增强）
- 访问用户主页获取完整信息
- 提取：粉丝数、笔记数、认证信息等

### 模块4：种子账号扩展（可选增强）
- 给定一批行业种子账号
- 采集其粉丝/关注列表中的同类型账号
- 递归扩展

### 模块5：数据输出
- 格式：CSV / JSON / Excel
- 附带采集时间、来源关键词等元数据

## 六、部署方式

### 模式A：CLI脚本（最简模式）
```bash
python collector.py --keywords "健身,瑜伽" --output result.csv
```
适合：本地一次性采集

### 模式B：FastAPI服务
```bash
uvicorn api_service:app --host 0.0.0.0 --port 8000
```
API端点：
- `POST /task` — 创建采集任务
- `GET /task/{id}` — 查询任务进度
- `GET /task/{id}/result` — 下载采集结果
适合：服务端持续运行

### 模式C：Web管理界面（Streamlit）
```bash
streamlit run web_app.py
```
提供可视化操作面板：
- 关键词管理
- 任务创建与监控
- 结果预览与导出
适合：运营人员直接使用

## 八、风险与应对

| 风险 | 应对措施 |
|------|----------|
| 小红书反爬升级 | 多账号轮换、随机延迟、页面特征模拟 |

| 采集效率低 | 多浏览器实例并发 + 任务队列 |
| 账号被封 | 自动切换备用账号、设置采集上限 |
